# Buena Vista Carwash

Responsive static website built with HTML, CSS, and a small amount of JavaScript. No build or package installation required.

## Run locally

```sh
cd /workspace/carwash
python -m http.server 8000
```

Open the served site in a browser. The site can be hosted on any static web host.

## Business photography

The owner's PDF supplied all seven original images. They are extracted and stored locally in `assets/`: five business photographs, the original logo, and the higher-resolution photo of the foam-covered SUV. The hero uses the SUV photograph with its front license plate blurred, the story uses the vacuum-area photo, and the gallery includes all five smaller photographs. Smaller source images are displayed in a compact gallery; higher-resolution originals can replace them later.

## Content review

- Address, phone, hours, and payment details come from the business owner's supplied information.
- Customer testimonials were supplied by the owner from in-person interviews. They appear below the hero and are labeled as in-person feedback, not Google reviews.
- No wash prices or business founding dates are invented.
- Google Maps iframe and Google Fonts require internet access. Fonts have system fallbacks.
